# C# Study

C# 기초부터 객체지향 프로그래밍까지 학습한 내용을 기록하는 저장소입니다.

## 학습 목표

- C# 기본 문법 복습
- 문제 해결 능력 향상
- 객체지향 프로그래밍(OOP) 이해
- 코드 가독성 및 유지보수 능력 향상
- Git 및 GitHub 활용 습관 형성

## 학습 방식

1. 개념 학습
2. 직접 코드 작성
3. 실행 및 오류 확인
4. 코드 리뷰 및 개선
5. GitHub에 학습 결과 기록

## 실행 방법

각 일차 폴더에서 다음 명령어를 실행합니다.

```powershell
dotnet run
```

> .NET SDK가 설치되어 있어야 합니다. 각 프로젝트의 `TargetFramework`는
> 사용 중인 SDK와 호환되는 버전으로 조정할 수 있습니다.
